# 🎱 Magic Eight Ball

A modern React implementation of the classic Magic Eight Ball. Users can ask a question, shake the Eight Ball, and receive a randomized response through an animated, polished user interface.

---

## Features

- 🎱 Custom CSS-built Magic Eight Ball
- ✨ Smooth floating animation
- 📳 Shake animation before revealing answers
- 💬 Randomized responses
- ✅ Input validation
- 🔄 Reset without reloading the page
- 🎨 Modern glassmorphism interface
- 📱 Responsive layout

---

## Technologies Used

- React
- JavaScript (ES6)
- CSS3
- HTML5

## Installation

Clone the repository:

```bash
git clone https://github.com/graceelliott8374-tech/magic-eight-ball.git
```

Navigate into the project:

```bash
cd magic-eight-ball
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
